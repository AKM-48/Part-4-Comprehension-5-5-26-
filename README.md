# Part 4 Comprehension: Level the Playing Field

A React/Vite web game for a school presentation about how football and sport can help spread messages about gender equality.

## Edit the Content

All presentation text, questions, answers, evidence quotes, and game rounds are in:

`src/data/content.js`

## Run Locally

```bash
npm install
npm run dev
```

## Build for GitHub Pages

```bash
npm run build
```

The project uses `base: "./"` in `vite.config.js`, so the built files work from a GitHub Pages project path.
